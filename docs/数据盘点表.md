## 六、阶段 1 清洗建议

1. 优先处理纯文字（txt/md），先让知识库「能跑起来」
2. docx 用 python-docx / pandoc 抽文字
3. 巨型手册的图片 OCR 可延后（先吃文字部分）
4. 统一元数据：来源目录、业务主题、日期
5. 写脱敏脚本（替换人名/客户名/订单号）
6. 客户原始订单 PDF 建议排除出知识库（保留在 raw 备查）
