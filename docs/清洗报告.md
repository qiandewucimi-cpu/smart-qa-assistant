## 二、脱敏规则（**7 类**）

### 2.1 词表替换（真实词表在本地 `maps_local.py`，已被 `.gitignore` 忽略，绝不入库）

| 类别 | 原名 → 化名 |
|---|---|
| 导师 / 讲师 | 5 位 → 导师A~E |
| 学员 | 9 位 → 学员A~I |
| 外部人员 | 5 位 → 外部人员A~E |
| 公司 | 39 条真实公司/工厂/地名 →「某外贸公司」等 |
| 工厂 | → 内地工厂 / 海外工厂 |
| 客户 | 16 条真实客户名（含英文抬头） → 客户A / 客户B |

> ⚠️ 教训：**脱敏脚本的映射表本身就是敏感信息**，不能随代码提交。正确做法是映射表放 gitignored 本地文件，代码只留脱敏框架。

### 2.2 结构化规则（能正则就别加词条，避免"打地鼠"）

| 规则 | 匹配形态 | 替换为 |
|---|---|---|
| 客户订单号 | 客户名 + 6 位以上数字 | `[订单号]` |
| 内部合同号 | `AB1CDE23-0059` 形态（2 大写+数字+3 大写+2 数字-4 数字） | `[内部合同号]` |
| 英文企业主体 | 词 + `GmbH/Ltd./LLC/Inc./KGaA/B.V.` 等后缀 | `[企业主体]` |
| 中文企业主体 | `XX国贸 / XX实业 / XX有限公司` | `[企业主体]` |
| 银行账号 | `0000-486217-837` 形态 | `[银行账号]` |
| SWIFT/BIC | **上下文锚定** `SWIFT/BIC: XXXXXXXX` | `[银行代码]` |
| 裸域名 / URL | `www.[链接]`、`https://…` | `[链接]` |
| 内网 IP | `10.x.x.x` 等 | `[内网地址]` |

> 关键细节：英文词条必须**忽略大小写 + 词边界**（OCR 大小写不可控；且防 `ABC` 命中 `ABCDEF`）；BIC 码必须上下文锚定，否则 `SHIPPING/MATERIAL/STANDARD` 等正常词会被误伤（命中数从 26 → 1）。
