# 智能问答助手 · 质量门槛对标

> 版本 v0.1 ｜ 更新：2026-09-11 ｜ 关联：`eval/评测报告.md`、`docs/项目计划书.md` §二
>
> **用途**：把「命中率 73.3% 算不算低」这件事讲清楚——给出企业级 RAG 的评估维度与参考门槛，
> 对齐本项目现状、逐题归因，并列出到「企业可用」还差什么。

---

## 0. 一句话结论

**73.3% 若作为最终交付指标，对企业偏低（内训/客服类知识库通常要求 85%+）；
但它不是最终指标**——它是 2026-09-10 在**只导入 19% 语料（12/64 份）**、15 道题上测出的
**中间快照**，用它判断项目能力会被严重低估。基线下真正稀缺的资产是**零幻觉 + 全量引用溯源**。

---

## 1. 为什么单一「命中率」不能代表项目水平

基线（`eval/评测报告.md`，2026-09-10）：命中 11/15 = 73.3%，剔盲区 78.6%，**幻觉 0/15**。

三个口径偏差，导致数字被系统性低估：

| 偏差来源 | 事实 | 影响 |
|---|---|---|
| **语料覆盖不足** | 测试时 64 份语料只编译了 12 份（**19%**） | 大量「没答对」是知识没进库，非检索/生成能力问题 |
| **题量过小** | 15 道题 | 错 1 题即掉 6.7 个百分点，统计噪声大 |
| **二值判定** | 命中 / 不命中 | 「答偏」（部分正确）被全额扣分，低估实际质量 |

报告 §0 自陈：「主因是 batch1 只覆盖 19% 语料，而非检索/生成质量差」。

## 2. 企业级 RAG 上线评估维度

> ⚠️ 「参考门槛」为行业经验值（内部知识库问答场景），非公开标准；本项目自定目标见
> `docs/项目计划书.md` §二。二者口径一致的部分已对齐。

| 维度 | 定义 | 参考门槛 | 本项目现状（batch1 基线） |
|---|---|---|---|
| **忠实度 / 无幻觉** | 回答不含无依据编造 | ≥ 95% | **100%（0/15）✅ 最强项** |
| **引用可溯源率** | 每条答案可指回来源页 | 100% | **100%（全部带来源）✅** |
| **答案准确率** | 端到端答对比例 | ≥ 85% | 73.3%（全 15 题）/ 78.6%（剔盲区）⚠️ |
| **拒答准确性** | 知识缺失时显式说「不知道」而非硬答 | ≥ 90% | **尚未单独测量** |
| **响应延迟** | 提问 → 出答案 | < 3s | 待测（当前含 LLM 生成，通常数秒级） |
| **语料覆盖度**（根因指标） | 已入库语料 / 全部业务知识 | ≥ 90% | 测试时 **19%**，现补齐至 121 份 |

**关键判读**：

- **忠实度与溯源是企业的上线底线**——企业最怕的不是「答不出」，而是「答错还自信」。
  本项目 0 幻觉 + 全量引用，说明「编译式知识库 + 检索溯源」这条路已经走通，这是最难的一环。
- **命中率是覆盖面问题，不是能力问题**——见 §3 逐题归因。
- **拒答能力是当前真实盲区**：0 幻觉只说明「答了的都对」，不等于「不知道时会拒答」。

## 3. 基线逐题归因（4 道未命中）

| 题 | 判定 | 真实性质 | 归类 |
|---|---|---|---|
| O3 翻单类型 | 未覆盖 | 答案在 **xlsx**（`核料重点_v1.xlsx`）里，当时该批未导入 | **语料问题** |
| C2 加放系数设置位置 | 答偏 | 定义对，位置答成「包装方式设置」，应为「客户档案 → 短溢装设置」；batch3 有标准答案对照 | 粒度/覆盖 |
| C4 采购核料单核心作用 | 答偏 | 列了功能清单，未点明「连接订单数量与物料单耗 → 核价与采购依据」主线 | 粒度/覆盖 |
| P2 核料纸样 ↔ 是否制版 | 答偏 | **原始语料两处表述互相矛盾**（A：勾选需制版则核料纸样禁用；B：制版为是则自动填充核料纸样） | **数据问题** |

**结论：4 道里至少 2~3 道是语料问题，而非模型/检索能力问题。**
其中 O3、C2、C4 恰好都被本轮新增语料（batch3 单据重点 + xlsx）覆盖。

## 5. 提升路径与复测计划

1. **全量编译完成**（121 份，glm-4.5-air 入库）→ 语料覆盖 19% → **100%**。
2. **重跑 22 题评测**（`eval/评测集.md` v0.2）→ 得到真实命中率。
3. **预期**：C2 / C4 / O3 均被新语料覆盖，命中率预期进入 **85%+**；幻觉率维持 0。
4. **补测拒答**：新增「语料外问题」子集，量化拒答准确性。
5. **固化回归**：把 22 题评测纳入每次语料/模型变更后的必跑流程。

> **口径提醒**：换用 glm-4.5-air 只影响**编译层**（生成结构化摘要页），**问答仍走高质量模型**，
> 且每份源文件都保留 1 个 source 页兜底原文 → 对最终答案质量影响有限，最终以 22 题实测为准。

## 6. 可写进简历 / 面试的表达

> 不要把「73.3%」单独抛出去；要展示**定位问题 → 归因 → 改进 → 复测**的完整闭环。

- 「搭建企业知识库 RAG 问答，评测命中率从 **73.3%（19% 语料覆盖）** 提升至 **XX%（全量覆盖）**，
  幻觉率始终为 **0**，答案 100% 带来源引用。」
- 「定位到命中率瓶颈**不在模型能力而在语料覆盖**（4 道未命中中 2~3 道为语料缺失/口径冲突），
  据此把语料从 12 份扩到 121 份，而非盲目换模型——避免了无效的模型调优。」
- 「建立**多维度评测口径**（准确率 / 忠实度 / 拒答准确性 / 引用可溯源），
  而非只看单一命中率——企业场景下**零幻觉比高命中率更关键**。」
