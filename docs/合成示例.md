# 公开合成示例

```bash
python scripts/demo_synthetic.py
```

仅需 Python 标准库，不读取私有语料、不启动 LLM-Wiki、不调用模型。

1. 使用现有 `clean_text.desensitize` 清理一段带合成内网地址的文本。
2. 精确查找“采购确认”，返回固定规则句与合成来源ID。
3. 对未收录问题返回无依据提示，来源为空。

这是帮助读者理解输入脱敏、来源与拒答接口的最小示例。精确匹配采用演示代码，不代表项目引擎的关键词/图谱检索，更不验证模型回答能力。合成来源ID只用于此脚本，不对应企业文档。

真正在线问答的依赖和验证路径见 [架构与演示](架构与演示.md)。历史私有语料成绩不能由本示例复算。
