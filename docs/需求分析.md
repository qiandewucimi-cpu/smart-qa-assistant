# 需求分析

> 阶段 0 产出 ｜ 更新：2026-09-09

## 1. 项目定位

基于企业私有知识库的智能问答助手，面向「产品/业务培训」场景，让培训期新人秒级检索到散落各处的培训知识，并带引用溯源。

## 2. 知识领域：产品/业务培训

- 内容类型：业务流程、产品功能、行业知识、话术、操作规范等。
- 影响：知识库分类与评测集需覆盖四类问题——概念类 / 流程类 / 操作类 / 时效类。

## 3. 用户画像

- 培训期新人（实习生 / 新入职员工）。
- 典型问题：「XX 流程怎么走？」「这个功能是什么意思？」「上次培训讲过 XX，在哪能找到？」。
- 特点：问题重复度高、需要引用溯源、需要时效性判断（旧知识会过期）。

## 4. 数据来源与现状

- 原始平台：飞书文档/群聊、腾讯文档/在线文档、会议纪要/转写。
- 现状：已离职，飞书已关闭；资料已提前下载保存到本地。
- 接入方式：本地文件导入（无需平台 API，更简单可控）。
- 数据形式：已盘点（173 文件 / 153MB，详见 `docs/数据盘点表.md`）。

## 5. LLM 选型

- 决策：国产大模型（成本低、合规、面试好讲）。
- 候选：DeepSeek / 通义千问 / 文心一言（具体待定，阶段 2 前确认）。

## 6. 关键风险

- 数据为真实公司资料：用于 demo 与简历前必须脱敏（隐去人名、内部敏感信息），避免合规风险。
- 数据规模已盘点：173 文件 / 153MB，以培训手册(docx)与会议纪要(txt)为主；风险转为「脱敏」与「图片 OCR 成本」。
