# 评测目录导航

## 评测集

- `评测集.md` / `评测结果_raw.json`：基础评测集与基线结果。
- `评测集_扩展.md` / `questions_ext.json`：扩展评测集。
- `评测集_扩展65.md` / `questions_ext65.json`：65 题扩展集。
- `拒答评测报告.md` / `拒答评测结果_raw.json`：语料内外拒答专项。

## 主要报告

- `评测报告_v0.2_全量.md`：首轮全量评测。
- `评测报告_v0.3_复测.md`：无向量检索复测。
- `评测报告_v1.0_检索深度与快模型.md`：检索深度和模型速度实验。
- `评测报告_v1.1_知识固化与稳定性.md`：FAQ 固化和重复评测。
- `评测报告_v1.2_框架失败续跑.md`：框架失败及续跑实验。
- `评测报告_v1.3_扩展集与框架失败成因.md`：扩展集和最终归因。

## 文件命名

- `评测结果_raw_ab_*`：A/B 对照实验原始结果。
- `评测结果_raw_ext*`：扩展集原始结果。
- `评测结果_raw_p0_*`、`*_stab_*`：问题修复及稳定性实验。
- `延迟基准_*`：端到端延迟测试。

这些原始结果用于复算报告结论。发布前必须运行：

```powershell
py scripts/sanitize_eval_results.py --check
```
